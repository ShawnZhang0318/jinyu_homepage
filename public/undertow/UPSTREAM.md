# Undertow

Source: [HaichaoLihc/create-photo-flipbook-ui / stream-implement-3d](https://github.com/HaichaoLihc/create-photo-flipbook-ui/tree/d7a43c979e9a2fb709e985d8df8c0d9ba805d034/ui-collections/stream-implement-3d/dist).
See [LICENSE](LICENSE) for the upstream MIT license.

The portfolio mounts this scene in a same-origin frame only while the rain view
is open. Adaptations include portfolio photo records and an empty state, local
story state instead of frame hash history, Chinese controls, reduced-motion
behavior and a pixel budget for large displays. No upstream demo photos, credits
or journal entries are included. The shader and WebGL helper files are unmodified.
